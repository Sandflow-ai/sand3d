Writing an assembly

Put the plan first, then the details, then the part builders. Each part has its own dimensions and origin; the head explains how they belong together.

1. Make the head a table of contents

The first function is named after the object. It calls part builders, places their results and returns assembly; it does not build geometry. Runners call this first function. Keep module-level code to imports and function definitions; a separate runner performs export.

A picnic table's head should read as tabletop, end frame, mirrored frame, benches. A turnstile head should show the frame, rotor and pawl with their pivots beside them. Extrusions buried in the head hide this plan and make parts harder to remove or reuse. Details that remain optional can hang from an assembly with attach.

The chair separates a plan, published anchors and removable details. Delete its add_back call and the same plan makes a stool.

Chair: plan, details, parts

Four legs and a seat establish the plan; the back and rails are attached afterwards. The render adds a fallback material.

The program, 60 lines
"""A chair, written as an assembly: the plan first, then the details, then the parts.

`chair` reads as a table of contents. `chair_frame` is the plan: the seat on its legs,
and the anchors the details need. Each `add_` function hangs one detail on those
anchors: delete its line and nothing else moves — without `add_back` it is a stool.
The parts come last, each built at its own origin, standing on z = 0.
"""
import sand3d as s3d


def chair(width=440, depth=420, seat_h=450):
    chair = chair_frame(width, depth, seat_h)   # the plan
    add_back(chair)                             # the details, on the plan's anchors
    add_rails(chair)
    return chair.root


# ---------------------------------------------------------------- the plan

def chair_frame(width, depth, seat_h, t=30, inset=35):
    """The seat on four legs. Publishes the width, the seat's height and the line
    the back stands on."""
    legs = s3d.at(leg(seat_h - t), on=s3d.grid(2, 2, width - 2 * inset, depth - 2 * inset))
    seat = s3d.at(seat_board(width, depth, t), z=seat_h - t)
    return s3d.assembly("chair", seat, legs, width=width, depth=depth, seat_h=seat_h, inset=inset,
                        back_y=depth / 2 - 20)


# ---------------------------------------------------------------- the details

def add_back(chair, h=420, t=24, button_d=16):
    """A panel standing on the seat's back edge, buttoned on its face."""
    back = s3d.at(back_panel(chair.width - 40, h, t), y=chair.back_y, z=chair.seat_h)
    # a side face's frame starts at z = 0, below the parent's origin, and its Y is up
    face = back.face("-Y").move(y=chair.seat_h + h * 0.6)
    buttons = s3d.at(s3d.dome("button", button_d, 5), on=s3d.grid(3, 2, 100, 110, on=face))
    s3d.attach(chair, "back", back, buttons)


def add_rails(chair, d=18, z=160):
    """A rail between the front and back legs, on each side."""
    # both=True: centred on its middle, so turned about X it spans the depth evenly
    rail = s3d.extrude("rail", s3d.circle(d), chair.depth - 2 * chair.inset, both=True)
    sides = s3d.grid(2, 1, chair.width - 2 * chair.inset, on=s3d.Frame((0, 0, z)))
    s3d.attach(chair, "rails", s3d.at(rail, rx=90, on=sides))


# ---------------------------------------------------------------- the parts

def seat_board(width, depth, t):
    return s3d.fillet(s3d.box("seat", width, depth, t), 8, edges="top")


def leg(h, foot=26, top=36):
    """Tapered, its foot on z = 0."""
    return s3d.cone("leg", foot, h, d2=top)


def back_panel(width, h, t):
    return s3d.fillet(s3d.box("back", width, t, h), 6, edges="top")

2. Write one function per distinct part

Build each part about its own origin. Parameters express what differs; return one object. Three differently sized levers should call one lever builder. A seesaw's matching crossrails should share one builder, with a mirrored copy for the opposite end, rather than duplicate six lines under two names.

How the pieces belong togetherUseResult
Fused permanentlyjoinOne solid with the first object's material
Separate but moving togethergroupEach keeps its mesh and material
Moving relative to one anotherjoint in the headParts connected through parent frames

assembly adds published anchors to a top-level group. A lone solid needs no wrapper group. Return it at its origin: if its builder places it at z = 50, a later at(..., z=100) resets it to 100. A child inside a group retains its 50-unit offset when the group goes to 100, reaching 150. Choose this hierarchy deliberately.

The lamp publishes a head anchor so its shade can be attached without rebuilding the stand.

Lamp with an attached shade

The stem stands on the base's top face. The shade attaches at the published head frame. The render adds a fallback material.

The program, 14 lines
import sand3d as s3d


def lamp(stem_h=300):
    base = s3d.revolve("base", [(0, 0), (70, 0), (60, 20), (0, 20)])
    stem = s3d.at(s3d.cylinder("stem", 12, stem_h), on=base.face("top"))
    lamp = s3d.assembly("lamp", base, stem, head=s3d.Frame((0, 0, 20 + stem_h)))
    add_shade(lamp)
    return lamp


def add_shade(lamp, d=180):
    shade = s3d.shell(s3d.cone("shade", d, 120, d2=d / 2), 1.5, open="top bottom")
    s3d.attach(lamp, "shade", s3d.at(shade, on=lamp.head))

3. Name each dimension once

Put main dimensions in keyword arguments, in millimetres unless the program selects another unit. Write a measured value once and derive dependent values as expressions. A freezer's cavity and rim cuts should follow width, depth, height, wall, lip and slot dimensions; unrelated heights and widths break when the cabinet changes size. A collar's taper should have its own dimension, not borrow the base's fillet radius by accident.

Target 15 numeric literals per part, with a ceiling of 40. Count defaults too; exclude 0, 0.5, 1, 2, 45, 90, 180, 270 and 360. Read every argument you declare. Avoid special cases such as if x == 28 and unexplained fractions that work only for the current measurements. Accept a slightly less exact match if fewer independent numbers make the model coherent. A joint origin copied from a source such as URDF is also a measurement: name it once.

The bracket is a small example: width, depth, thickness, hole diameter and pitch describe its purpose.

A parameterized plate

The hole pitch is a dimension, not two unrelated hole coordinates. The render adds a fallback material.

The program, 8 lines
import sand3d as s3d


def bracket(w=80, d=40, t=6, hole_d=6.6, pitch=50):
    plate = s3d.extrude("plate", s3d.rect(w, d, r=4), t)
    s3d.hole(plate, hole_d, on=s3d.grid(2, 1, pitch, 0))
    s3d.fillet(plate, 1, edges="top")
    return plate

4. Place each part once in its parent's frame

The head places top-level parts with at. Part functions place their own children. Derive a placement from a dimension when that is the relationship; use a face, bbox or local frame when contact or attachment is the relationship.

A lamp stem should stand on its base, rather than use two unrelated measured world heights. A bowl on a stem uses the stem's height. An eyeglass arm should be drawn in its own frame, not as world-coordinate spline points with the head's translation subtracted from every point. See Frames and placement.

5. Repeat with frames and mirror a copy

Use on=grid(...), ring(...) or along(...) for repeated placements. Use transform(copy(placed), mirror="x") for the opposite side of a pair. at sets a place; transform makes the mirror image. Do not reconstruct rings with sine and cosine in a placement loop.

Three bunk-frame posts at -233, -140 and -47 hide a pitch of 93. Name the pitch and use a three-site grid centred at -140 instead. The rack shows both repetition and mirroring:

A rack from one grid and one mirror

The peg prototype is consumed by frame-list placement. The returned list can go directly into join. The render adds a fallback material.

The program, 12 lines
import sand3d as s3d


def rack(n=4, pitch=30, depth=40, t=5):
    base = s3d.extrude("base", s3d.rect(n * pitch, depth, r=3), t)
    pegs = s3d.at(s3d.cylinder("peg", 6, 20), on=s3d.grid(n, 1, pitch), z=t)         # a copy per frame
    hook = s3d.at(s3d.extrude("hook", s3d.rect(4, 12), 12), x=n * pitch / 2 - 4, z=t)
    image = s3d.transform(s3d.copy(hook), mirror="x")                                # its image across x = 0
    s3d.join(base, pegs, hook, image)                                                # a list is its elements
    s3d.hole(base, 4, on=s3d.grid(2, 1, (n - 1) * pitch).move(y=depth / 2 - 6))
    s3d.chamfer(base, 0.6, edges="peg")
    return base

6. Use the verb that names the shape

Do not replace a named operation with a coordinate table. Assembly programs use neither bpy nor bmesh. A free form without a matching verb may still need points.

ShapeExpression
Rotational bodyrevolve(name, profile)
Hollow open solidshell(ob, t=wall, open="top")
Bore or bolt circlehole(ob, d=diameter, on=frames)
Bent tubewire(name, path, d=diameter, fillet=radius)
Changing cross-sectionloft(name, station(...), ...)
Long body drawn from viewsbody(name, plan, top, bottom)
Band following a pathstroke(path, thickness)

A station describes height, width, depth, x/y offset and squareness n: 2 for an ellipse, 4 for a rounded box. A few stations describe a taper, bulge or drift. A nail shaft can be three named sections; a tray is a box shelled open at the top. For a soup bowl, describe the outer profile and shell the revolved solid, rather than type a second inner curve point by point.

Spoon and fork

Two builders share a lofted handle. The spoon is hollowed; the fork intersects a slotted head with a curved plate. The render wrapper calls both builders, separates them along Y and adds a fallback material.

The program, 61 lines
"""A spoon and a fork, from generic verbs — the regression test for "the vocabulary has a
hole": MeshCoder had to hard-code both.

Millimetres; the piece lies along +X from its business end, Z up. The handle is shared:
a loft of rounded sections along a gently rising line, narrow at the neck and widening
to a rounded end.
"""
import math

import sand3d as s3d


def handle(length=135, neck=(8.5, 2.6), end=(24, 3.2), rise=16, start=(0, 0, 0), stations=7, end_steps=6):
    """Sections from the neck to the end of the handle, square to its line; the last
    ones close it on a half circle in plan, so the end is round."""
    x0, y0, z0 = start
    r = end[0] / 2
    body = length - r                      # where the round end begins

    def place(x, width, thick):
        u = (x - x0) / length
        return s3d.at(s3d.superellipse(width, thick, 4), x=x, y=y0, z=z0 + rise * (3 * u ** 2 - 2 * u ** 3), rz=90)
    sections = []
    for k in range(stations):
        u = k / (stations - 1)
        sections.append(place(x0 + body * u, neck[0] + (end[0] - neck[0]) * u ** 1.6,
                              neck[1] + (end[1] - neck[1]) * u))
    for k in range(1, end_steps + 1):
        a = math.radians(85 * k / end_steps)
        sections.append(place(x0 + body + r * math.sin(a), end[0] * math.cos(a), end[1] * (1 - 0.3 * k / end_steps)))
    return s3d.loft("handle", *sections, follow=True)


def spoon(bowl=(62, 42), depth=13, wall=1.4, rim_r=0.5):
    """A bowl — half an ellipsoid, hollowed, its rim softened — and the handle."""
    length, width = bowl
    cup = s3d.scale(s3d.sphere("bowl", 1), (length, width, 2 * depth))
    s3d.split(cup, s3d.Frame((0, 0, depth)), keep="below")
    cup = s3d.at(cup, z=-depth)                                        # its rim on z = 0
    s3d.shell(cup, wall, open="cut")
    s3d.fillet(cup, rim_r, edges="shell")
    return s3d.join(cup, s3d.at(handle(start=(length / 2 - 3, 0, -wall / 2)), z=0))


def fork(head=(48, 25), tines=4, gap=2.2, root=17, t=2.2, bend_r=140):
    """A flat head cut into `tines` from its tip back to `root`, bent to a curve by
    keeping what a curved plate shares with it — and the handle."""
    length, width = head
    outline = s3d.poly([(-length, -width / 2), (0, -width / 2 + 3), (8, -4.5), (8, 4.5), (0, width / 2 - 3),
                        (-length, width / 2)], fillet=[4, 0, 3, 3, 0, 4])
    pitch = width / tines
    for k in range(1, tines):
        y = -width / 2 + k * pitch
        outline = outline - s3d.at(s3d.slot(2 * (length - root) + gap, gap), x=-length, y=y)
    prism = s3d.extrude("head", outline, 60, both=True)
    steps = 24
    curve = [(bend_r * math.sin(a), 0, bend_r * (1 - math.cos(a)))       # through the neck, rising to the tips
             for a in (-0.42 + 0.5 * k / steps for k in range(steps + 1))]
    plate = s3d.sweep("bend", s3d.rect(t, 4 * width), curve)
    s3d.intersect(prism, plate)
    return s3d.join(prism, handle(start=(6, 0, -t / 4)))

7. Give visible parts materials

When appearance matters, assign each part a material and colour once, before repeating it. Shape-only CAD data can omit materials. On a group, material reaches descendants without their own material; the nearest material assignment wins.

join keeps the first object's material. Join only what should share one colour; use group to preserve separate materials. A row of oak planks should receive its material before the grid creates copies. See Materials and media.

Tufted chair with removable trim

Lofts describe the seat and back, dents form the tufts, and anchors carry buttons and rows of nails. This repository example is shape-only; the render adds a uniform fallback material, not an upholstery material scheme.

The program, 135 lines
"""A tufted chair: a buttoned back rolling over at the top, a domed seat on a nailed
apron, four tapered legs.

Millimetres, Z up, the chair's front towards -Y; built as its left half's legs, the
right ones mirrored. The architecture is the seat on its legs; the back and every
row of trim are details added to it: deleting `add_back` leaves a stool, and the
back's tufts follow the width they are given.
"""
import json
import math
import sys

import sand3d as s3d


def tufted_chair(width=520):
    chair = chair_frame(width)
    add_back(chair)
    add_seat_nails(chair)
    return chair.root


def chair_frame(width=520, depth=480, seat_z=430, inset=50, floor=0):
    seat = upholstered_seat(width, depth)
    legs = []
    for leg, y in ((front_leg, -(depth / 2 - inset)), (rear_leg, depth / 2 - inset)):
        left = s3d.at(leg(), x=-(width / 2 - inset), y=y, z=floor)
        legs += [left, s3d.transform(s3d.copy(left), mirror="x")]   # the right one: its image across x = 0
    return s3d.assembly("chair", s3d.at(seat.root, z=seat_z), *legs,
                        seat=seat, width=width, seat_z=seat_z, rear_y=depth / 2)


def add_back(chair, behind=-30, above=200):
    back = tufted_back(chair.width)
    s3d.attach(chair, "back", s3d.at(back.root, y=chair.rear_y + behind, z=chair.seat_z + above))
    add_buttons(back)
    add_back_nails(back)


def add_seat_nails(chair, pitch=22, d=10, h=5):
    """One nail every `pitch` along the seat's seam, round its front and sides."""
    seat = chair.seat
    spots = s3d.snap(seat.parts, s3d.along(seat.seam, pitch))
    s3d.attach(seat, "seat_nails", *[s3d.at(s3d.dome("nail", d, h), on=f) for f in spots])


def add_buttons(back, d=16, h=3):
    s3d.attach(back, "buttons", *[s3d.at(s3d.dome("button", d, h), on=f) for f in back.tufts])


def add_back_nails(back, pitch=22, d=10, h=5, face=((220, -230), (226, 150)), reach=400):
    """A row up each side of the back's face, where its cover is nailed to the frame,
    from (x, z) to (x, z), found from in front, `reach` away."""
    spots = []
    for side in (-1, 1):
        (x0, z0), (x1, z1) = face
        spots += s3d.snap(back.parts, s3d.along([(side * x0, -reach, z0), (side * x1, -reach, z1)], pitch),
                          direction=(0, 1, 0))
    s3d.attach(back, "back_nails", *[s3d.at(s3d.dome("nail", d, h), on=f) for f in spots])


# ---------------------------------------------------------------- parts, in the order they are called

def section(z, w, d, x=0, y=0, n=2, taper=0):
    """One cross-section of a loft: a superellipse `w` wide and `d` deep, squareness
    `n` (2 an ellipse, 4 a box with round corners), its +Y side narrowed by `taper`,
    centred at (x, y, z)."""
    return s3d.at(s3d.superellipse(w, d, n, taper), x=x, y=y, z=z)


def upholstered_seat(width=520, depth=480, taper=0.04, squareness=6, board=-8,
                     crown=((15, 3, 3, 0), (35, 12, 10, 4), (55, 30, 24, 8), (68, 90, 72, 12), (76, 190, 160, 18)),
                     apron=60, dip=15, wall=8, seam_up=6, seam_out=10):
    """A cushion domed over a board, an apron hanging round it. `crown` is the dome,
    level by level: (height, inset at the sides, inset front and back, shift back)."""
    w = width / (1 + taper)  # the loft's mean width; the front edge is `width`
    cushion = s3d.loft("cushion", section(board, w, depth, n=squareness, taper=taper),
                       *[section(z, w - 2 * side, depth - 2 * end, y=back, n=squareness, taper=taper)
                         for z, side, end, back in crown])

    def drop(x):  # how far the apron hangs below the board: deepest mid-front
        return apron + dip * math.cos(math.pi * x / width) ** 2

    hem = s3d.superellipse(w - wall, depth - wall, squareness, taper).loops[0].pts
    skirt = s3d.loft("apron", *[s3d.at(s3d.superellipse(drop(x), wall, squareness), x=x, y=y, z=board - drop(x) / 2,
                                       ry=-90) for x, y in hem], follow=True, loop=True)
    # the seam the nails follow: just outside the apron, round the front and sides
    # but not the back, which the back of the chair covers — from the middle of the back round
    rim = s3d.superellipse(w + 2 * seam_out, depth + 2 * seam_out, squareness, taper).loops[0].pts
    start = min(range(len(rim)), key=lambda i: abs(math.atan2(rim[i][1], rim[i][0]) - math.pi / 2))
    seam = [(x, y, board - drop(x) + seam_up) for x, y in rim[start:] + rim[:start] if y < depth / 2 - seam_out]
    return s3d.assembly("seat", cushion, skirt, parts=[cushion, skirt], seam=seam)


def front_leg(height=420, profile=((0, -10, 30, 30), (210, -4, 36, 36), (420, 0, 44, 44))):
    """A square leg with round corners, tapering to its foot, which steps forward.
    `profile` is (z, y, width, depth) from the floor up; its origin is under its foot."""
    body = s3d.loft("front_leg", *[section(z * height / profile[-1][0], w, d, y=y, n=4) for z, y, w, d in profile])
    return s3d.group("front_leg", s3d.at(body, y=-profile[0][1]))


def rear_leg(height=420, profile=((0, 16, 30, 30), (210, 6, 36, 36), (420, 0, 44, 44))):
    """The back leg, raking back to its foot. Its origin is under its foot."""
    body = s3d.loft("rear_leg", *[section(z * height / profile[-1][0], w, d, y=y, n=4) for z, y, w, d in profile])
    return s3d.group("rear_leg", s3d.at(body, y=-profile[0][1]))


def tufted_back(width=520, drawn_for=520, squareness=4, profile=(
        (-260, 0, 440, 50),    # foot, behind the seat: z, y, width, depth
        (-140, 6, 460, 60),
        (-20, 14, 470, 64),    # the cushioned middle
        (90, 24, 480, 66),
        (170, 36, 490, 72),    # leaning back
        (205, 58, 490, 70),    # over the top
        (180, 82, 490, 60),    # down the back
        (130, 88, 490, 46)),   # tucked under
        tuft_rows=((-60, -120), (-52, -40), (-44, 40), (-34, 120)), tuft_pitch=80, tuft_margin=100, tuft_r=55,
        tuft_depth=20):
    """A cushioned panel rising from the seat and rolling over backwards, one loft
    along its own centre line; buttoned on a diamond lattice, each tuft row (y, z),
    the rows' columns staggered. The profile's widths are those of a `drawn_for` chair."""
    widen = width - drawn_for
    body = s3d.loft("back", *[section(z, w + widen, d, y=y, n=squareness) for z, y, w, d in profile], follow=True)
    reach = int((width / 2 - tuft_margin) / tuft_pitch)  # columns each side of the middle
    lattice = [(j * tuft_pitch, y, z) for i, (y, z) in enumerate(tuft_rows)
               for j in range(-reach, reach + 1) if (i + j) % 2 == 0]
    tufts = s3d.snap(body, lattice)
    s3d.dent(body, tufts, tuft_r, tuft_depth)
    return s3d.assembly("tufted_back", body, parts=[body], tufts=s3d.snap(body, tufts))


if __name__ == "__main__":
    s3d.empty_scene()
    s3d.export(s3d.group("tufted_chair", tufted_chair(**json.loads(sys.argv[2] if len(sys.argv) > 2 else "{}"))),
               sys.argv[1])

8. Reuse one frame per joint

Keep the parent frame, placed child and joint together in the head. For a numeric source pivot, read f = local(parent, x, y, z, rx, ry, rz) once. Use it in both at(child, on=f) and joint(name, child, f, ...). Each moving part can then be removed with its own lines.

local works in the parent's own space even deep in a chain. Do not compose source coordinates into world coordinates. A source joint axis must first be turned by its source roll, pitch and yaw; direction-string joint axes use the space the parent lives in. Check the sign with the right-hand rule: a correct pivot with the wrong axis sign can open a door into its cabinet.

Fixed details need no joint. Put them in the moving parent's group before declaring its joint, or they can stay behind. Return mechanisms at rest, every joint at zero, with no pose in the builder. Unjointed parts have nothing to pose. The gate example is an explicit demonstration exception: it poses one leaf to show the swing.

A sliding cabinet lid and its hatch illustrate a chain: the two lids use frames on the cabinet and opposite slide axes; the hatch uses a frame read on its moving lid. A rotary spindle must use the same pivot for placement and movement, rather than two nearby frames.

Mirrored hinged leaves

The second leaf copies the first leaf's joint, then mirrors the part and pivot. One leaf is posed to 60 degrees for this demonstration. The render adds a fallback material.

The program, 14 lines
import sand3d as s3d


def gate(w=750, h=1200, post=100):
    l_post = s3d.at(s3d.box("post", post, post, h + 300), x=-w - post / 2)
    r_post = s3d.transform(s3d.copy(l_post), mirror="x")
    board = s3d.at(s3d.box("board", w, 40, h), x=-w / 2, z=150)                    # from the post to x = 0
    handle = s3d.at(s3d.cylinder("handle", 20, 60), on=s3d.bbox(board, "+Y").move(x=60 - w / 2))  # near x = 0
    leaf = s3d.group("leaf", board, handle)                                        # the handle moves with it
    s3d.joint("hinge", leaf, s3d.bbox(l_post, "+X+Y"), axis="+Z", range=(0, 90))   # the post's edge it opens toward: +X turns toward +Y
    twin = s3d.transform(s3d.copy(leaf), mirror="x")                               # its image, hinged at x = +w: opens toward +Y too
    gate = s3d.assembly("gate", l_post, r_post, leaf, twin)
    s3d.pose(leaf, 60)   # shows the swing; a program returns at rest
    return gate

See Articulation and assembly for the complete joint API.

Natural forms

Separate random streams

Use one derived seed per call. Two vary calls with the same seed replay the same stream, so the longest leaf also becomes the widest. Use seed + 1, seed + 2, or seed * 100 + k for part k, including calls to jitter and scatter.

For conditional draws in a loop, such as rejections, choices or colours, create one random.Random(seed + k) per part. Keep draw order stable. Use a declared seed parameter or leave it unused; do not hide it with _ = seed. A root with seed=0 defines the reproducible build.

Shape the outline before the skin

Small noise on a symmetric base gives a rough regular shape. First change proportions and silhouette: uneven hull points, varied lengths, a bend, twist or taper, or displacement with features as large as the part. Then add fine grain with a different seed. Inspect the outline before increasing sampling.

Grow organs from their attachment

along points frame Z along a curved stem's tangent; cylindrical phyllotaxis points it radially outward. Spin around the tangent before leaning away. A subsequent turn(ry=60) departs 60 degrees from that tangent.

Build each organ from its base at its origin, along its own +Z. A sweep scale law [(0, 0), (.35, 1), (1, 0)] puts its first pole at the attachment. Angular jitter preserves the root; positional jitter detaches it.

Leaves on a curved stem

Tangent frames spin before they lean. Angular jitter and independently varied lengths keep each leaf's base on the stem.

The program, 31 lines
"""Lateral leaves attached by their bases to a curved stem."""
import sand3d as s3d


def curved_stem():
    path = stem_axis()
    stem = stem_part(path)
    frames = s3d.along(path, count=13, spin=137.508, span=(.12, .92))
    frames = frames.turn(ry=60).jitter(rx=5, ry=8, rz=12, seed=2)
    lengths = s3d.vary(24, 5, len(frames), seed=3)
    leaves = [s3d.at(leaf_part(f"leaf{k}", length), on=frame)
              for k, (frame, length) in enumerate(zip(frames, lengths))]
    return s3d.assembly("curved_stem", stem, leaves)


def stem_axis():
    return s3d.spline([(0, 0, 0), (8, 0, 35), (-5, 4, 75), (12, 0, 110)])


def stem_part(path):
    stem = s3d.wire("stem", path, [(0, 2.4), (1, .8)])
    s3d.material(stem, "rubber", color="#48643e")
    return stem


def leaf_part(name, length=24, width=9, thickness=.8):
    leaf = s3d.sweep(name, s3d.ellipse(width, thickness),
                     [(0, 0, 0), (0, 0, length)],
                     scale=[(0, 0), (.35, 1), (1, 0)])
    s3d.material(leaf, "rubber", color="#749950")
    return leaf

Derive contact from geometry

Attach to the actual parent with a face, snap, or the final frame of along(path, count=2). Do not measure offsets from a render: attachment must survive changes of seed. Compose frames with on=, not translations added across rotated parents. Keep local callback coordinates, sampled sites in the sampled mesh's parent space and world positions distinct.

A pond filled against its banks

The lawn is cut first, then filled to a level. The returned water follows the container rather than a separately measured shoreline. The render uses a 25 mm swell and sky lighting so the water surface is visible.

The program, 14 lines
import sand3d as s3d


def pond(size=3000, depth=500, basin=(1600, 1000), dig=400, margin=60, swell=0, wavelength=700):
    """A garden pond: still water, or a wind-blown swell `swell` high."""
    lawn = s3d.material(s3d.box("lawn", size, size, depth), "grass")
    hollow = s3d.extrude("hollow", s3d.ellipse(*basin), dig + margin, taper=-30)
    s3d.cut(lawn, s3d.at(hollow, z=depth - dig))
    water = s3d.fill("water", lawn, depth - margin)
    s3d.material(water, "water", absorb="#5f9c8a", absorb_distance=800)
    if swell:
        waves = s3d.waves(wavelength, direction=30, sharpness=0.5, spread=15)
        s3d.displace(water, swell, wavelength / 8, noise=waves, direction="+Z", faces="top")
    return s3d.group("pond", lawn, water)

Select sites once

Filter sampled frames with one predicate. Pass every kept site through one placement helper shared by populations such as stones and plants. Use the count that remains, not the requested sample count. For example, a terrain filter can keep frames above a height and outside a circular clearing before enumerating the retained sites and deriving one seed per stone.

Put repeated stages in a table

Leaf tiers, flame layers, smoke columns and layered fungi should use one loop over a parameter table, with a derived seed per item. Store height, scale and rotation together. Refactoring must preserve table order, random draw order and fusion order.

Dress every component and respect resolution

Natural forms require materials. Give flesh, stalk and seeds their own assignments; likewise leaf blades and veins. Use natural presets with explicit colours for the intended mood.

For low-poly work, facets(n, smooth=False) reaches field, displace and blend surfaces too; a hull follows its input points. Low-poly is not finer geometry with noise painted on it. Preserve intentional angular silhouettes, raise n if a branch or hole disappears, and use facets("auto") to restore adaptive resolution. A face budget is a ceiling, not a target. See Resolution.

Weight stack

The plate column publishes anchors for bumpers, guide rods and selector. Each detail can be removed independently. The shape-only source receives a fallback material in the render.

The program, 116 lines
"""The weight stack of a cable machine.

A column of plates resting in two rubber bumpers, two guide rods standing over the
top plate, and the selector: two nuts and a stem on top, the pin's head at the
chosen plate and a spring lanyard hanging from under the nuts down to it.

Millimetres. The stack's frame has its origin under the middle of the lowest
plate, X along the plates, -Y towards the user.
"""
import json
import sys

import sand3d as s3d


# ---------------------------------------------------------------- the object: architecture first, then details

def weight_stack(n_plates=14, selected=9):
    """The plates, then each detail on their anchors. Any `add_` line can be deleted:
    the rest of the object does not change."""
    stack = plate_column(n_plates)
    add_bumpers(stack)
    add_guide_rods(stack)
    add_selector(stack, selected)
    return stack.root


def plate_column(n_plates=14, pitch=24, plate_h=22, plate_d=100, guide_spacing=300):
    """`n_plates` plates `pitch` apart. Publishes where details go: every plate's
    height, the top face, the front face and the two guide lines."""
    bottoms = [i * pitch for i in range(n_plates)]
    plate_z = [z + plate_h / 2 for z in bottoms]
    return s3d.assembly("weight_stack",
                        *[s3d.at(weight_plate(d=plate_d, h=plate_h), z=z) for z in bottoms],
                        plate_z=plate_z, top=bottoms[-1] + plate_h, front=-plate_d / 2,
                        guides=(-guide_spacing / 2, guide_spacing / 2))


# ---------------------------------------------------------------- details, each on the stack's anchors

def add_bumpers(stack, sink=10):
    """Two rubber cups under the guide lines, taking the lowest plate `sink` deep."""
    s3d.attach(stack, "bumpers", *[s3d.at(bumper(), x=x, z=sink, anchor="top") for x in stack.guides])


def add_guide_rods(stack, gap=8):
    """Two rods on the guide lines, standing `gap` above the top plate."""
    s3d.attach(stack, "guide_rods", *[s3d.at(guide_rod(), x=x, z=stack.top + gap, anchor="bottom")
                                      for x in stack.guides])


def add_selector(stack, selected=9, nut_t=6, nut_gap=4, head_out=12, lanyard_y=-28):
    """On the top plate, two nuts and the stem; the lanyard's loop sits under the
    upper nut and its spring hangs in front, down to the pin head at plate `selected`."""
    upper = stack.top + nut_t + nut_gap     # under the upper nut
    pinned = stack.plate_z[selected]
    s3d.attach(stack, "selector",
               s3d.at(hex_nut(t=nut_t), z=stack.top, anchor="bottom"),
               s3d.at(hex_nut(t=nut_t), z=upper, anchor="bottom"),
               s3d.at(selector_stem(), z=stack.top),
               s3d.at(pin_head(), y=stack.front - head_out, z=pinned, rx=90),
               s3d.at(spring_lanyard(length=upper - pinned), y=lanyard_y, z=(upper + pinned) / 2, rz=-90))


# ---------------------------------------------------------------- parts, in the order they are called

def weight_plate(w=420, d=100, h=22, hole_d=16, edge_r=2):
    """A steel plate with softened edges, drilled front to back for the selector pin."""
    plate = s3d.fillet(s3d.box("weight_plate", w, d, h), edge_r)
    return s3d.hole(plate, hole_d, on=plate.face("-Y").move(y=h / 2))


def bumper(d_foot=50, d_mouth=46, h=60, wall=2):
    """A rubber cup the stack rests in, open at the top."""
    cup = s3d.revolve("bumper", [(0, -h / 2), (d_foot / 2, -h / 2), (d_mouth / 2, h / 2), (0, h / 2)])
    return s3d.shell(cup, wall, open="top")


def guide_rod(d=25, length=900, collar_d=35, collar_h=20):
    """A round rod with a collar at its foot."""
    foot, head = -length / 2, length / 2
    return s3d.revolve("guide_rod", [(0, foot), (collar_d / 2, foot), (collar_d / 2, foot + collar_h),
                                     (d / 2, foot + collar_h), (d / 2, head), (0, head)])


def hex_nut(across_corners=32, hole_d=16.5, t=6):
    return s3d.extrude("hex_nut", s3d.polygon(6, across_corners) - s3d.circle(hole_d), t, both=True)


def selector_stem(d=15, h=30, wall=1.5):
    """The top of the stem that threads the plates, an open sleeve."""
    return s3d.tube("selector_stem", d, d - 2 * wall, h)


def pin_head(d=36, t=3, boss_d=12, boss_t=6, hole_d=8):
    """The head of the selector pin, a disc with a boss, facing the user."""
    return s3d.revolve("pin_head", [(hole_d / 2, -boss_t / 2), (boss_d / 2, -boss_t / 2), (boss_d / 2, boss_t / 2 - t),
                                    (d / 2, boss_t / 2 - t), (d / 2, boss_t / 2), (hole_d / 2, boss_t / 2)])


def spring_lanyard(length=150, loop_d=44, loop_gap=40, neck=40, coil_x=24, lean=12, coil_d=4, wire_d=2.2,
                   pitch=2.6):
    """A loop lying flat on top, round the selector stem and open by `loop_gap`
    degrees, and a close-wound spring hanging `length` down from it, `neck` away
    from the loop's centre and leaning `lean` outwards by its foot."""
    top = length / 2 - wire_d / 2
    loop = s3d.arc((coil_x - neck, 0, top), loop_d / 2, loop_gap / 2, 360 - loop_gap / 2)
    hanging = s3d.at(s3d.helix(coil_d, pitch, 2 * top), x=coil_x, z=top, rx=180)   # from the loop, down
    coil = [(x + lean * (top - z) / (2 * top), y, z) for x, y, z in hanging.points]
    return s3d.wire("spring_lanyard", list(loop.points) + coil, wire_d)


if __name__ == "__main__":
    s3d.empty_scene()
    s3d.export(s3d.group("weight_stack", weight_stack(**json.loads(sys.argv[2] if len(sys.argv) > 2 else "{}"))),
               sys.argv[1] if len(sys.argv) > 1 else "weight_stack.glb")
