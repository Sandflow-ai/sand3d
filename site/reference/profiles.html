Profiles and outlines

Draw a flat region, then give it thickness or use it as a section. Profiles live in XY; paths describe a route. The examples give profiles a thin extrusion so their outlines are visible.

rectcircleellipseslotpolygonpolyarctangent_arcsplinesuperellipsestationtextoffsetstrokewrapmirror

Centred shapes

Lengths use the program's unit, millimetres by default. extrude lifts a profile along Z; box is the extrusion of a rect. Use at to place a profile or its solid.

rect, circle, ellipse, slot, polygon

rect(w, d, r=0, chamfer=0)
circle(d)
ellipse(w, d)
slot(l, d)
polygon(n, d)

These profiles are centred on the origin. Choose a rectangle, circle, ellipse, round-ended slot or regular polygon, then extrude it.

w, d
Width along X and depth along Y; for circle and polygon, d is a diameter.
r, chamfer
Rectangle corner radius or corner cut distance; both default to zero.
l
Slot's overall length along X; d is its width. If l is at most d, the result is a circle of diameter d.
n
Polygon side count. Corners lie on a circle of diameter d, with one corner on +X.

Example

import sand3d as s3d


def build():
    profiles = [s3d.rect(24, 18, r=3), s3d.circle(20), s3d.ellipse(24, 16),
                s3d.slot(26, 12), s3d.polygon(6, 22)]
    parts = []
    for i, profile in enumerate(profiles):
        part = s3d.extrude(f"shape{i}", profile, 3)
        parts.append(s3d.at(part, x=(i % 3) * 32, y=(i // 3) * 30))
    result = s3d.group("profiles", *parts)
    s3d.material(result, "plastic", color="#729ba0")
    return result

Rectangle, circle and ellipse in the first row; slot and hexagon in the second. Each is extruded 3 mm.

Limits. Corner rounding or cutting must fit on the adjacent sides.

See also: poly, extrude

Draw an outline

poly, arc, tangent_arc

poly(pts, fillet=0, chamfer=0)
arc(center=(0, 0), r=1, start=0, end=360, *, through=None, to=None)
tangent_arc(to)

poly joins XY points with straight lines and closes the outline. Mix points with arc, tangent_arc and open spline runs to draw curved portions without listing sampled points yourself.

pts
An ordered sequence of points and curved runs. The last point joins back to the first; repeating the first point is optional.
fillet, chamfer
Round or cut corners between two straight segments only. Supply one value for all eligible corners or a list indexed by input item; zero leaves a corner alone.
center, r
Arc centre and radius, or (rx, ry) for an elliptical arc.
start, end
Arc angles in degrees. Increasing angles run anticlockwise; decreasing angles run clockwise.
through, to
Inside poly, arc(through=p, to=q) starts at the previous point, passes through p and ends at q. Give both, without the centre/radius/angle form.
to
tangent_arc ends here, leaving the previous point tangent to the preceding outline.

Example

import sand3d as s3d


def build():
    profile = s3d.poly([(-24, -14), (14, -14),
                       s3d.tangent_arc((24, -4)), (24, 6),
                       s3d.arc(through=(16, 16), to=(8, 6)),
                       s3d.spline([(8, 6), (-8, 18), (-24, 6)])])
    result = s3d.extrude("outline", profile, 3)
    s3d.material(result, "plastic", color="#729ba0")
    return result

Straight sides, a tangent corner, a three-point arc and a spline form one closed plate.

Limits. These outlines are planar. A tangent arc needs a preceding point and an incoming direction; a through arc needs a preceding point. Corner fillets and chamfers that exceed a side raise an error.

See also: spline, stroke, wire

An arc is also a path on its own: s3d.arc(r=20) draws a full circle path. Feed it to wire or sweep for a solid. A point list for poly need not be centred: it is drawn where its coordinates say. For an irregular outline, points can also come from frame origins, for example s3d.poly([tuple(f.origin)[:2] for f in s3d.ring(8, 20).jitter(x=2, y=2, seed=3)]).

spline

spline(pts, closed=False, tangents=None, loop=False)

Interpolate a smooth curve through 2D or 3D points. The default is an open path; closed=True makes a planar profile, while loop=True makes a smoothly closed path that may travel through 3D space.

pts
Points the curve passes through, in order.
tangents
Optional (start, end) directions for an open curve. Either can be None; only direction matters, not magnitude.
closed
Return a flat profile for extrude, revolve or loft.
loop
Join the last point smoothly to the first as a path for wire, sweep or along.

Example

import sand3d as s3d


def build():
    points = [(-18, 0), (-12, 16), (12, 16), (18, 0), (0, -12)]
    with s3d.facets(64):
        plate = s3d.extrude("profile", s3d.spline(points, closed=True), 3)
        path = s3d.spline(points, loop=True)
        rim = s3d.at(s3d.wire("loop", path, 2), x=48)
        open_path = s3d.spline(points)
        line = s3d.at(s3d.wire("open", open_path, 2), x=96)
    result = s3d.group("curves", plate, rim, line)
    s3d.material(result, "plastic", color="#729ba0")
    return result

The same points as an extruded closed profile, a loop path made into a wire, and an open path made into a wire.

Limits. closed and loop are mutually exclusive. Neither accepts end tangents; a loop needs at least three points. A supplied tangent must be nonzero and point along the curve, not backwards across it.

See also: poly, wire, sweep, Paths and fields

Build a spline and the wire or sweep using it inside the same facets(...) context. Increasing facets only around the solid does not remove stations already sampled in its path. Fixed facets controls turns across sections and along paths. More rings cannot repair a self-crossing: reduce the wire diameter or soften the curvature. Sweep and loft caps are named start and end, not bottom and top.

Sections for lofting

superellipse, station

superellipse(w, d, n=2, taper=0)
station(z, w, d, x=0, y=0, n=2, taper=0)

superellipse moves from an ellipse at n=2 toward a rounded rectangle at n=4. station makes that same profile and places it at a height and XY centre, ready to become a loft section.

w, d
Section width along X and depth along Y.
n
Shape exponent; lower values make a more diamond-like outline, higher values a squarer one.
taper
Narrows the +Y side and widens the -Y side, producing an egg-like outline.
z, x, y
Section height and centre, as in at(superellipse(w, d, n=n, taper=taper), x=x, y=y, z=z).

Example

import sand3d as s3d


def build(thickness=3, gap=36):
    parts = []
    for i, exponent in enumerate((2, 4)):
        profile = s3d.superellipse(28, 24, n=exponent)
        parts.append(s3d.at(s3d.extrude(f"section{i}", profile, thickness), x=i * gap))
    egg = s3d.superellipse(28, 24, taper=.45)
    parts.append(s3d.at(s3d.extrude("egg", egg, thickness), x=2 * gap))
    shell = s3d.loft("loft", s3d.station(0, 28, 24, n=4),
                     s3d.station(16, 20, 18, x=3), s3d.station(28, 10, 12, x=6))
    parts.append(s3d.at(shell, x=3 * gap))
    result = s3d.group("sections", *parts)
    s3d.material(result, "plastic", color="#729ba0")
    return result

Ellipse, rounded rectangle, tapered ellipse, then a loft through three stations with changing width, depth and centre.

Limits. Use positive n and nonzero depth for an ordinary outline. A zero width and depth together make a pole, not an area to extrude.

See also: loft, body, displace

For a soft mass, extrude or loft ellipse-like sections, then displace at the scale of the outline before adding fine grain. The organic forms guide develops that technique.

Letters

text

text(s, size, font=None)

Turn text into a profile centred on its visible ink. Extrude the outline for raised letters, or use its solid as a cutting tool.

s
Text to outline.
size
Font em size in program units; this is not the exact visible letter height.
font
Path to a .ttf or .otf file; None uses Blender's built-in font.

Example

import sand3d as s3d


def build(size=28, thickness=4):
    letters = s3d.text("S3D", size)
    result = s3d.extrude("letters", letters, thickness)
    s3d.material(result, "plastic", color="#729ba0")
    return result

S3D outlined at an em size of 28 mm and extruded 4 mm.

Limits. Text with no outline, such as an empty string, raises an error.

See also: extrude, cut

Change a profile

Profiles support + for union and - for difference. These are 2D operations before extrusion.

offset

offset(p, t)

Grow a profile all around by t, with rounded outward corners. A negative t shrinks it; placement of a placed profile is preserved.

p
The original profile.
t
Signed offset distance in program units.

Example

import sand3d as s3d


def build(width=28, depth=20, offset=3, thickness=3, gap=42):
    profile = s3d.rect(width, depth)
    parts = []
    for i, amount in enumerate((-offset, 0, offset)):
        grown = s3d.offset(profile, amount)
        parts.append(s3d.at(s3d.extrude(f"offset{i}", grown, thickness), x=i * gap))
    result = s3d.group("offsets", *parts)
    s3d.material(result, "plastic", color="#729ba0")
    return result

The same rectangle shrunk by 3 mm, unchanged, and grown by 3 mm.

Limits. Large offsets can cross narrow features; this operation does not resolve self-intersections into a new outline.

See also: stroke, wrap

stroke

stroke(path, t)

Turn a flat open path into a closed band of width t, centred on the path. Ends are square and corners are mitred; extrude the band for a strap, bracket or wall.

path
An open spline, arc or XY point sequence with the same curved runs as poly.
t
Positive width, half on either side of the path.

Example

import sand3d as s3d


def build(radius=24, width=5, thickness=3, gap=62):
    path = s3d.arc(r=radius, start=20, end=160)
    band = s3d.stroke(path, width)
    curved = s3d.extrude("curved", band, thickness)
    bent = s3d.stroke([(-20, -10), (12, -10), (12, 16)], width)
    corner = s3d.at(s3d.extrude("corner", bent, thickness), x=gap)
    result = s3d.group("bands", curved, corner)
    s3d.material(result, "plastic", color="#729ba0")
    return result

A circular arc becomes a curved strap; an angular point path becomes a mitred bracket.

Limits. Closed paths and profiles are refused. The band must not cross itself: use a thinner band or a less tightly turning path. Draw in XY, then place the resulting profile with at.

See also: arc, offset, extrude, revolve

For a band around a closed profile p, use s3d.offset(p, thickness) - p instead.

wrap

wrap(*profiles)

Draw the convex outline around profiles and XY points. Placed profiles keep their in-plane positions; straight spans meet curved portions tangentially, and explicit points keep their corners.

profiles
Profiles, points, or lists of them. Together they must span an area.

Example

import sand3d as s3d


def build(gap=48, belt_width=3, thickness=4):
    wheels = [s3d.at(s3d.circle(24), x=-gap / 2), s3d.at(s3d.circle(16), x=gap / 2)]
    outline = s3d.wrap(*wheels)
    belt = s3d.extrude("belt", s3d.offset(outline, belt_width) - outline, thickness)
    hubs = [s3d.extrude(f"wheel{i}", p, thickness * 1.5) for i, p in enumerate(wheels)]
    result = s3d.group("belt_and_wheels", belt, *hubs)
    s3d.material(result, "plastic", color="#729ba0")
    return result

A belt made from offset(outline, 3) - outline wraps two wheels of different diameters.

Limits. At least three non-collinear sampled points are needed. Convex wrapping fills concavities.

See also: offset, hull

mirror

mirror(p, flip="x")

Return the union of a profile and its reflected image. Draw one half to make a symmetric whole, including any in-plane placement before reflection.

p
Profile to combine with its image.
flip
Coordinate whose sign changes: x by default, or y.

Example

import sand3d as s3d


def build(thickness=3, gap=66):
    half = s3d.poly([(0, -18), (16, -12), (24, 8), (0, 18)])
    single = s3d.extrude("half", half, thickness)
    whole = s3d.at(s3d.extrude("whole", s3d.mirror(half), thickness), x=gap)
    result = s3d.group("symmetry", single, whole)
    s3d.material(result, "plastic", color="#729ba0")
    return result

The original half on the left and its union with the reflection on the right.

Limits. This verb takes profiles. For a solid's image, use s3d.transform(s3d.copy(ob), mirror="x").

See also: transform, copy
