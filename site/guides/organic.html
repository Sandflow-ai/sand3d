Organic forms

Build the structure before adding surface noise. A rock needs a silhouette, a coral needs connected branches or ridges, and a fungus needs lobes that meet its stem.

A first rock

import sand3d as s3d


def rock(seed=0):
    width, depth, height = 90, 70, 60
    points = s3d.scatter(28, (width, depth, height), surface=True, seed=seed + 1)
    points = points.jitter(x=8, y=8, z=8, seed=seed + 2)
    stone = s3d.hull("stone", points)
    s3d.displace(stone, amount=7, size=40, step=12, seed=seed + 3)
    s3d.displace(stone, amount=.5, size=6, step=6, seed=seed + 4)
    return s3d.material(stone, "rock", color="#807569")

A hull of 28 seeded points, with broad relief and a second, smaller grain. The point count sets the large facets before displacement adds detail.

Start with points scattered over an ellipsoid's surface. Jitter them to break regular spacing, then wrap them with hull. This gives a convex mass: any inward pockets between the points are lost. Broad displacement can break that convexity; a second pass adds grain. Keep both seeds explicit so the same program makes the same rock.

Choose the structure

Choose a verb for the shape you need before choosing a noise pattern.

NeedMethod
A convex, faceted masshull wraps points
Several masses flowing into one anotherblend fuses them and fills the meeting creases
Relief on a surface that already existsdisplace moves its vertices
A local hollowdent pushes in a patch
Cavities, tunnels or folded sheetsfield builds the boundary of a density function

Noise cannot rescue a missing structural feature. Keep coral branches attached, fungal lobes connected to stems, and the rock's important outline visible.

Holes, folds and lobes

A field describes inside and outside throughout a box. Its boundary becomes the surface, so it can form tunnels and cavities as well as outer relief. Combine a broad envelope with seeded noise or waves to shape folded sheets, brain-coral ridges, fungal lobes or rock masses. The field reference explains the density convention, bounds and sampling parameters.

import numpy as np
import sand3d as s3d


def sea_sponge(seed=0, d=100, pore=26, cell=2.1):
    def density(x, y, z):
        z, k = z - (d + 4 * cell) / 2, 2 * np.pi / pore
        ball = np.sqrt(x * x + y * y + z * z) - d / 2
        gyroid = np.sin(x * k) * np.cos(y * k) + np.sin(y * k) * np.cos(z * k) + np.sin(z * k) * np.cos(x * k)
        wobble = s3d.noise(x / pore, y / pore, z / pore, seed=seed)
        return np.maximum(ball, np.abs(gyroid + .3 * wobble) - .5)
    sponge = s3d.field("sponge", (d + 4 * cell, d + 4 * cell, d + 4 * cell), density, cell=cell)
    return s3d.assembly("sea_sponge", s3d.material(sponge, "sand", color="#d9a441"))

A spherical envelope clips a periodic density to form an open lattice.

Start with coarse cells to find the overall shape within the build budget. Then check that holes stay open and narrow connections survive. Refine only where the visible geometry needs it; never refine a field solely to carry finer colour. For relief on an otherwise adequate surface, use displacement instead of rebuilding the whole volume.
