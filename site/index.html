3D modeling in Python

Build 3D objects from profiles, solids, edits, frames and joints. sand3d gives Python programs a vocabulary for geometry and assemblies over Blender's bpy.

Build a first part

Install sand3d and write a mounting bracket. Round its named top edge, drill two holes, and export it as a GLB.

Find a verb

The reference groups the API by family. Each entry gives its signature, parameters and limits. Examples show how to use the verbs together.

Put parts together

Concepts explains names, frames and placement. Writing an assembly shows how to build a lamp and its shade, a rack of repeated parts, and a mirrored gate with hinges.

Model a subject

Follow a guide for water, fire and smoke, trees and vegetation, terrain, organic forms, colour, glass and ice or mesh resolution.

Export a model

Export and settings covers GLB, URDF, USD, IFC, OBJ and STL. Export scales program lengths to metres.

Give the vocabulary to an LLM

For LLMs links to the API, assembly guidelines and task guides for a model's prompt.

Citation

See CITATION.cff for citation metadata.

Datasets
